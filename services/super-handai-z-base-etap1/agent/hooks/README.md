# Внешние хуки onSessionStart (Этап 1, Модуль 2)

Каталог внешних хуков агента. В начале **каждой задачи** (сессия = исполнение
одного ТЗ) движок запускает все `*.hook.js` из этого каталога.

## Контракт

- **Только** файлы `*.hook.js` в корне этого каталога (allowlist имён:
  `[a-z0-9][a-z0-9._-]*.hook.js`). Подкаталоги, `bad.js`, скрытые файлы — игнор.
- Запуск **plain node**: `[process.execPath, <абсолютный путь>]`, `shell: false`
  — никаких `exec`, `&&`, `cmd.exe` (Windows-камни Ponytail #593/#527/#569).
- Аргументы хуку НЕ передаются; всё окружение — через stdout.
- Хук печатает строки контекста в stdout. Вывод нормализуется: **BOM-strip**
  (U+FEFF в начале), **CRLF → LF**, пустые строки выбрасываются.
- Каждая строка попадает в additionalContext-канал: журнал (`FEATURE_CTX`),
  отчёт задачи (раздел «КОНТЕКСТ ФИЧ»), MCP `get_status`.
- **Never-block**: бюджет времени на хук = бюджет слота (по умолчанию 2000 мс,
  см. `setSlotBudgetMs` в features/registry.ts). Зависший хук убивается,
  задача продолжается; ошибка — silent fail в заметках.
- Exit-код не 0 — не роняет задачу: заметка `external hook <файл>: exit=N`.

## Пример

```js
// hooks/example.hook.js
console.log('Перед задачей: проверь бэкап и EXPECT-проверки');
```

Файлы `.hook.js` — обычный JavaScript под той же версией Node, что и агент.
Windows-специфика (BOM в UTF-8 из блокнота, CRLF) обрабатывается раннером
автоматически — см. `src/core/externalHooks.ts` и `test/hooks-contracts.test.ts`.
