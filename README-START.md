# Super_HandAI_z Light — установка с нуля (пошагово)

Прочти целиком один раз, потом выполняй по пунктам. Все ссылки — официальные
источники. Время установки: ~30-40 минут (в основном скачивания).

---

## ШАГ 1. Каркас папок


```text
C:\Super_HandAI_z\          ← сюда распакуется архив проекта
C:\Utilit\node\             ← сюда — Node.js (см. Шаг 2)
```

Если проект-архив уже скачан с GitHub — распакуй его содержимое в
`C:\Super_HandAI_z\` (папки agent, docs, data... должны оказаться прямо там).

## ШАГ 2. Node.js 20

1. Скачай zip по ссылке выше
2. Распакуй в `C:\Utilit\node\` — так, чтобы `C:\Utilit\node\node.exe` существовал
3. Проверка: `C:\Utilit\node\node.exe -v` → должно быть `v20.x.x`

⚠️ Важно: именно v20 — нативный модуль PTY ставится под конкретную мажорную версию.

## ШАГ 3. PowerShell 7

1. Скачай zip по ссылке выше (~105 МБ; если скачалось сильно меньше — файл битый, качай заново)
2. Распакуй **содержимое zip** прямо в `C:\Super_HandAI_z\runtime\pwsh\` (без вложенной папки!)
3. Проверка: `C:\Super_HandAI_z\runtime\pwsh\pwsh.exe` существует

## ШАГ 4. PortableGit

1. Скачай self-extracting архив по ссылке выше
2. Запусти его, целевая папка: `C:\Super_HandAI_z\runtime\git\`
3. Проверка: `C:\Super_HandAI_z\runtime\git\bin\bash.exe` и `C:\Super_HandAI_z\runtime\git\cmd\git.exe` существуют

## ШАГ 5. Зависимости агента

Запусти `install.cmd` из корня проекта (двойной клик). Жди `=== ready ===`.
Нужен интернет: ставятся express, ws, zod и нативный `@lydell/node-pty`
(Windows prebuilt — под твою версию Node).

## ШАГ 5.2 Проверка компонентов и генерация токена

Запусти  setup.cmd

## ШАГ 6. Первый запуск агента

Запусти `run.cmd` из корня. Увидишь:

```text
[ok] node v20.x.x
[ok] pwsh
[ok] bash
[ok] git
[ok] node-pty
...
UI: http://127.0.0.1:8787/?t=<токен>
```

Открой напечатанный URL в Chrome — это панель агента: слева поле ТЗ,
справа живой терминал. **Токен в URL меняется при каждом старте —
запомни это место консоли, он понадобится для моста (Шаг 9).**

## ШАГ 7. Первый прогон без чата (проверка рук)

1. Открой `docs\samples\tz1-csv2json.md` в блокноте, скопируй всё содержимое
   НО: если файл начинается с ```markdown / ```tz — эти строки-ограды НЕ копируй
   (копируй от строки `# ЗАДАЧ:` до последней строки GIT commit)
2. Вставь в поле ТЗ в UI → ▶ Запустить
3. Смотри терминал: npm установит пакеты, tsc соберёт, конвертер отработает
4. Жди `СТАТУС: SUCCESS` в поле Отчёт (потребуется интернет для npm)

Не SUCCESS — см. раздел «Проблемы» ниже.

## ШАГ 8. Chrome-профиль и Tampermonkey (для моста)

1. Tampermonkey по ссылке выше → Добавить в Chrome
2. `chrome://extensions` → Tampermonkey → Подробности → включи **«Разрешить
   открывать локальные файлы»** (иначе мост не увидит пак-файлы)
3. Открой `GLM-Agent Bridge U1\src\bridge.user.js` в блокноте, скопируй ВСЁ
4. Tampermonkey → Создать новый скрипт → вставь с заменой → Сохранить (Ctrl+S)

## ШАГ 9. Связка моста с агентом

1. В панель паков скопируй стартовый пак: содержимое
   `GLM-Agent Bridge U1\Temp\pack\` — уже в проекте, ничего делать не нужно
2. Открой chat.z.ai (GLM-5.3-Flash), войди в аккаунт
3. Справа вверху появится панель `bridge: web-dev · 4 шабл. (агент)`
   — если видишь её и счётчик шаблонов, связка работает
4. Кнопка «🧹 Очистить workspace» при первом нажатии спросит токен агента —
   скопируй его из URL панели (часть после `?t=`) и вставь один раз

## ШАГ 10. Первый боевой цикл с GLM

1. В z.ai нажми кнопку моста **«⤓ Системный промпт»** → текст вставится в поле
   ввода → отправь его (GLM войдёт в роль постановщика ТЗ)
2. Опиши задачу обычными словами (или кнопка «▶ Новая задача»)
3. GLM ответит блоком ТЗ → над блоком появится кнопка **«⧉ ТЗ»** → клик → ТЗ в буфере
4. Вставь в поле агента (или кнопка «⧉ Вставить из буфера») → ▶ Запустить
5. После завершения — **«⧉ Копировать отчёт»** → верни в чат GLM
6. GLM разберёт отчёт и выдаст следующее ТЗ — цикл замкнулся

## ПРОБЛЕМЫ

| Симптом | Лечение |
|---|---|
| `pwsh.exe not found` | PowerShell распакован с вложенной папкой — файлы уровнем выше |
| Ошибка node-pty при старте | Node не v20 или install.cmd не выполнен — проверь и повтори |
| `shell: bash` шаг падает | bash.exe не в `runtime\git\bin\` — переустанови PortableGit |
| Панель моста: «пак недоступен» | Агент не запущен, или выключен «Разрешить локальные файлы» (Шаг 8.2) |
| Кнопка «⧉ ТЗ» не появляется | Обнови страницу (F5); проверь, что скрипт включён в Tampermonkey |
| Порт 8787 занят | Уже запущен другой агент — закрой или правь `agent\data\state\config.json` |
| npm-шаги падают | Нет интернета/прокси — прогон smoke-задачи без npm (см. docs\samples) |
